# MG 动画分镜（120 秒升级版）

分辨率：1920×1080；16:9；60 FPS；总时长：120 秒；总帧数：7,200。共 28 个镜头，帧区间左闭右开、无间隙、无非设计重叠。

## 视觉连续性规则

- 保留近黑背景、暖金强调、米白宋体、少量低饱和红、档案细线与科学仪器图形；无页眉页脚。
- 无配音；独立的主叙事字幕负责连续讲述，画面内关键词、核心判断、示例对话和研究范围与图形动画配合。
- 动画以 Remotion 帧计算驱动。采用线条绘制、遮罩揭示、字形位移、空间推拉、形态匹配与跨镜头接力；不使用随机噪声、装饰粒子或自主循环。
- 对话文字不冠以真实产品或真实用户来源；画面中不出现“虚拟 / 虚构”示例标签。
- 训练过程用独立视觉时段呈现，清楚区分当前回答上下文与可能影响后续模型倾向的训练反馈。
- 重要限定与来源在画面中可读。研究图形不暗示论文没有报告的统计幅度。

## 关键科学视觉的执行边界

### 当前对话与偏好反馈（S09–S13）

S09–S10 表示一次对话中的上下文与回答。S11–S12 切换到训练阶段，按输入、候选生成、比较、反馈、后续倾向的顺序推进。字幕把时间关系讲清：眼前回答来自当前对话上下文；训练反馈可能塑造后续表达倾向。动画不展示真实神经网络、奖励权重或概率值。

### 2025 年产品案例（S14–S17）

时间线依据 OpenAI 公开复盘。更新、用户反馈、回滚、初次说明与进一步复盘按日期出现；成因仅写为多项变化可能共同作用。所有屏幕文字为事实概括，不使用伪造引语或仿造官方 UI。

### 研究结果（S19–S21）

49% 同层展示特定人际建议任务、11 个模型、研究来源及比较范围。S20 使用无刻度方向线。S21 从一次谄媚式回答分出两项结果，并显示单次互动、特定实验条件与 N=2,405；不外推到长期效应。

## 动态与排版验收点

- 28 个镜头使用不同景别和主体轮廓；相邻镜头不连续采用三次相似布局。
- S12→S13 以移动的反馈节点汇入“回答倾向”；S14→S15 以档案时间轴节点继续推进。
- S26 只做钟面回扣；完整问句只在 S27 出现；S28 只留下最终句与 2 秒静止。
- 主叙事字幕逐镜头对齐毫秒时间轴；S12 与 S27 的换句连续，S28 保留末两秒无字余韵。
- 运动不依赖墙上时钟、随机数或 CSS 自动循环。
