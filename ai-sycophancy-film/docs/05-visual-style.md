# 视觉美术规范

## 1. 视觉定位

**复古学术纪录片 × Editorial Motion Design**。画面像一册被翻开的研究档案：近黑底、米白文字、少量暖金；以清晰的中文排版、圆形/细线母题和有来由的镜头移动建立节奏。它不模拟产品 UI，不使用蓝色霓虹、漂浮粒子或无意义数据图。

用户提到的 `assets/reference/style-reference.png` 在当前工作区不存在；本规范依据用户消息中描述的设计语言制定，不能声称已读取或复刻参考图。

## 2. 色彩 Token

```ts
export const COLORS = {
  background: "#0D0C09",
  backgroundSoft: "#191710",
  gold: "#C5A574",
  ivory: "#E8E0D1",
  muted: "#8D877B",
  line: "#51483B",
  danger: "#A34D40",
} as const;
```

- 背景占绝大部分画面；纹理不应降低文字对比度。
- 金色用于年份、章节编号、关键信息和路径节点；同一场景不把所有元素染金。
- 红色仅用于“无根据肯定”“研究限制提示”等少量语义警示，面积低于画面约 3%。
- 说明文字与背景至少保持清楚的视觉分离；不使用低对比度细金字承载长句。

## 3. 字体系统与授权

| 使用角色 | 字体 | 用途 |
| --- | --- | --- |
| 中文标题 / 哲学性文字 | Noto Serif SC | 标题、关键判断、片尾文字 |
| 中文字幕 / 图表注释 | Noto Sans SC | 解释文字、来源、研究范围、信息标签 |
| 英文标题 / 年份 / 章节数字 | Cormorant Garamond | 年号、英文主标题和大型数字 |
| 英文正文 / 历史档案 | EB Garamond | 档案索引与英文小标题 |
| 文学化引用 | Ma Shan Zheng | 少量用于片尾，不承担长篇信息 |

许可与覆盖：五种字体均从 Google Fonts 官方仓库获取，按字体目录的 OFL 条款使用；项目随附每种字体对应的许可证。中文字体使用 Noto Serif SC 与 Noto Sans SC 变量 TTF；拉丁字体使用 Cormorant Garamond、EB Garamond 变量 TTF；Ma Shan Zheng 使用静态 TTF。工程指定这些字体文件，不依赖系统回退字体决定成片字形。

- [Noto Sans SC 官方元数据](https://github.com/google/fonts/blob/main/ofl/notosanssc/METADATA.pb)
- [SIL Open Font License 1.1（Noto Serif SC）](https://github.com/google/fonts/blob/main/ofl/notoserifsc/OFL.txt)
- [SIL Open Font License 1.1（Noto Sans SC）](https://github.com/google/fonts/blob/main/ofl/notosanssc/OFL.txt)

## 4. 排版层级

画幅 1920×1080，建立 12 栏网格；最大内容宽度 1,600 px，左右安全边距 160 px，网格间距 32 px。重要文字至少距画面边缘 100 px，顶/底安全距离至少 100 px。

| 层级 | 字号参考 | 行距 | 使用方式 |
| --- | ---: | ---: | --- |
| 开场 / 片尾关键句 | 116–144 px | 1.18 | 单句居中或偏轴；每屏不超过 2 行 |
| 概念标题 | 88–104 px | 1.2 | 1–2 个关键词，不塞定义段落 |
| 正文说明卡 | 48–56 px | 1.42 | 每屏 1–3 行，按节奏分批显示 |
| 数据说明 | 40–48 px | 1.35 | 49% 等核心结果旁显示范围限定 |
| 辅助注释 / 来源 | 24–28 px | 1.35 | 重要事实注释不低于 24 px |
| 英文 / 档案编号 | 20–24 px | 1.3 | 仅作注记，不与中文争夺主层级 |

- 动态标题是叙事文字；说明卡承担限制条件和研究出处。两者不得挤在同一文字块。
- 句子超过 2 行时，按意义拆成多个动画段，每段维持至少 2 秒可读时间。
- 默认使用左对齐和明确基线；只有开场、章节名、片尾使用居中排版。
- 标点紧跟语义单元，避免单独一行；数字与单位固定使用不可拆分的排版组。

## 5. 图形与构图

- 基本图形：圆盘、开放圆环、直线、档案卡、方形遮罩；少量纸张折线作批注。
- 线宽：常规 1.5 px，构图关键线 2 px，焦点轮廓最高 3 px；全片不使用默认发光描边。
- 视觉层级：1 个主体 + 1 组解释关系 + 可选 1 个来源/限制注释；每帧最多一个高亮重点。
- 允许不对称排版、大幅留白和分屏；不使用常驻 HUD、伪代码、随机数字、装饰网格。
- 数据只呈现已核实的 11、49%、N=2,405 等论文结果，并在画面附近持续显示任务范围；反馈循环不显示论文未报告的概率值。

## 6. 动画缓动与摄像机

- 入场主曲线：`Easing.bezier(0.22, 1, 0.36, 1)`，用于线条展开、排版归位。
- 位移缓入：`Easing.bezier(0.4, 0, 0.2, 1)`，不对所有文本应用弹性回弹。
- 结束曲线：`Easing.bezier(0.4, 0, 1, 1)`；文字需读完后才退出。
- `spring()` 仅用于少量圆点或纸卡；阻尼取高值，避免弹跳广告感。
- 镜头推进/拉远通常控制在 1–4%；横移通常不超过画幅 5%；需要阅读的文字在镜头运动中保持稳定。
- 每个镜头只设一个主要运动方向；文字读入、圆环扩展、时间线推进、镜面复制等运动都必须解释内容关系。
- 所有位移、裁切、透明度和字形变化用 `useCurrentFrame()` / `interpolate()` 确定性计算。任何伪随机质感均使用固定种子预生成。

## 7. 转场规范

1. 闹钟圆盘形变为对话气泡，再由句号圆弧引出最终回声圆环。
2. 文字匹配：立场 / 事实的词位转换为“不等号”，进入比较画面。
3. 遮罩揭示用于档案卡、术语标题和事实限制；掩模边缘跟随纸张结构。
4. 时间线采用真实的水平推进，由圆点大小/色彩变化显示日期，而不是每卡单独淡入。
5. 分屏通过中央竖线拆合，画面语义同源，不做孤立的左右两页。
6. 片尾逐层移除图形，再停留在开场圆盘与最后一句。

短转场按毫秒设计并由 60 FPS 时间轴统一转换；关键镜头交接通常控制在 400–800 ms。全片为 7,200 帧；接力线在相邻镜头共享端点，不改变总时长。

## 8. 胶片质感与字幕

- 底纹采用静态、可重复的细纸颗粒；固定种子预生成或用单张纹理复用，透明度约 1–2%。
- 暗角边缘极轻；不加逐帧随机颗粒、闪烁、胶片刮痕或大面积模糊。
- 只使用用户提供的背景音乐，不添加独立音效；音乐不循环，并在片尾 2 秒渐弱。
- 影片不使用配音；独立主叙事字幕承担连续讲述，与画面关键词和事实注释形成两层信息。
- 主字幕使用 Noto Sans SC，约 38 px，居中放在下方安全区，单行优先、最多两行；轻微下方渐层只负责阅读对比，不做成页脚条或卡片。
- `output/subtitles.srt` 与主字幕逐条对应，不是语音识别稿。`final-clean.mp4` 保留动画内的关键词和事实文字，但不叠加主字幕轨。

## 9. 代表性镜头静态设计

### A. S05 礼貌与迎合的对照

黑色画布。中央细线一分为二，左侧小标题“理解感受”，右侧“替事实下结论”。两侧使用同一条闹钟情境，正文米白同字号；右侧“你完全正确”被低饱和红细框圈出。画面不加情境来源标签，避免把示例写成产品记录。四角留空，避免 UI 卡片感。

### B. S12 偏好反馈核心

先用独立的当前对话画面呈现用户立场与一条回应，再切换到训练阶段。训练画面依次表现输入、候选回答、偏好比较、反馈信号和后续表达倾向；字幕沿时间顺序解释反馈如何可能影响后续回答。数据、指令、反馈和评测多条路径共同汇入回答倾向，不画网络结构、权重或概率。

### C. S19 研究结果

中央大字“49%”周围展示 11 枚等大模型标记；其上方同层标出“特定人际建议任务”，下方说明 AI 肯定用户行为频率与人类回答的比较，并以 24 px 以上文字注明研究来源与任务范围。数字不表示所有 AI 对话的普遍比例。

### D. S28 片尾

回到开场钟面后，只在 S27 显示一次完整开放问题。S28 留下“时针仍走，答案尚未定论。”，少量使用 Ma Shan Zheng；暖金钟弧保持未闭合，最后 2 秒静止，无 CTA 或感谢语。
