# 28 镜头视觉升级清单

## 审视结论

第一版已完成 28 个镜头、帧驱动 SVG、84 张入场/主体/出场 QC 帧和 150 秒预览。当前主要问题是 Scene.tsx 把大多数画面固定成“章节眉题 + 左侧文案 + 右侧 700×620 图”，Artwork.tsx 又在相邻镜头重复使用同一尺寸的线框。信息正确，但观看节奏容易落成动态幻灯片。

升级原则：保留既有黑金、米白宋体、档案细线和仪器制图；改变镜头空间占比、画面轴线、景别和图形的时间关系。尽量让信息通过路径、形态、比较和运动发生，文字只给观众命名关键对象与结论。

## 相邻镜头节奏审查

镜头景别交替采用全屏仪器、倾斜对话、中央字卡、全屏分屏、路径图、档案横移、圆形镜面、远景回声和极简片尾。不得连续三个镜头使用同一构图模板。细线和圆点承担跨镜头匹配，不用淡入淡出掩盖布局重复。

## 实现与验收约定

- 所有动作使用 Remotion 当前帧确定性计算。
- 反馈路径使用 SVG path 和 dashoffset/坐标插值，显式分阶段叙述完整因果链。
- 全屏、分屏、档案和中心字卡由独立 layout 变体控制；相邻镜头 layout 不相同。
- 重要标题/判断保留完整可读时间；技术解释使用短关键词与可视化过程。
- 每个镜头重新输出入场、主体和出场帧；重制 preview.mp4 与 final-clean.mp4 后用 FFprobe 核对。
