# 制作报告

更新时间：2026-10-08

## 成片规格

- 画面：1920×1080，16:9。
- 帧率：60 FPS；总时长 120 秒；7,200 帧。
- 镜头：28 个 Scene，毫秒时间轴连续。
- 讲述：MG 动画、画面内文字和主叙事字幕；无配音、无独立音效。
- 音乐：用户提供的 `BGM.mp3`；只混入这一条背景音乐，按 120 秒输出并在最后两秒淡出。

## 视觉与叙事升级

- 保留近黑、暖金、米白和复古档案字体体系，使用用户指定的 Google Fonts 字体组合及其 OFL 许可证。
- 将主叙事字幕与关键词排版分层：下方安全区使用 Noto Sans SC，渐层仅用于文字对比，不形成页脚卡片。
- 修复正式合成未挂载主字幕层的问题；`MainFilm` 现在烧录主叙事字幕，`MainFilmClean` 保持无主字幕轨。字幕稿存在不再被误当作画面字幕已完成。
- 删除底部免责、提示式小字；把科学范围自然并入主字幕及靠近数据的标题。例如 49% 位于“特定人际建议任务”范围内，S20 使用无刻度方向箭头，S21 展示单次回答结果分叉和 N=2,405。
- S10–S13 用连续叙事区分当前对话与训练阶段，并解释偏好信号如何可能与数据、指令和评测共同塑造后续表达倾向；没有把边界条件另做页脚。
- S23–S25 将提醒式文案改为可执行的核验路径：找薄弱前提、换立场追问、把回答带回证据重新判断。
- 保留 S12→S13 的移动节点接力、S14→S15 的档案时间轴接力、回音室分叉以及片尾钟面回扣。
