# Vibe Knowledge Festival

一个持续扩展的知识短片与视觉叙事样例集合。每个子目录代表一个独立样例，包含自己的代码、制作文档和运行说明；后续样例可作为新的同级目录加入。

## 样例

### AI 谄媚性：为什么 AI 总是顺着你说话？

使用 React、TypeScript、SVG 与 Remotion 制作的中文 MG 科普微纪录片，以动画和主体字幕讲解 AI 谄媚性、偏好反馈与相关研究。

- 项目目录：[ai-sycophancy-film](ai-sycophancy-film/)
- 项目说明：[ai-sycophancy-film/README.md](ai-sycophancy-film/README.md)
- 研究、文案与分镜：[ai-sycophancy-film/docs/](ai-sycophancy-film/docs/)

## 仓库约定

- 一个样例一个目录，目录内维护独立的开发与渲染说明。
- 生成的视频、关键帧和本机依赖不提交到仓库。
- 用户提供的音乐只有在确认具备公开分发授权后才加入仓库。
- 字体与其他第三方素材应附带许可证或来源说明。
